# Illustrative offline default profile

These report.md, report.json and self-contained report.html samples are generated by the actual native constructors with private offline fixtures. They are not deployment records or live provider checks. Every artifact has unknown presence and an empty physical provider ID. `declared` means included by the native constructor, not a calculated deployment action. Host integrations are supplied external fixtures. Regenerate from the repository root with `./preview.sh -output-dir ../docs/artifacts`. The launcher runs the CLI from infrastructure, so a custom relative output path is resolved there. The default launcher saves run outputs separately under repository-root deployment-reports/preview.
